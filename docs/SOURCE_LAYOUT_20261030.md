# 英文文件命名与中文界面

应用名称为“精析智评”。文件夹与文件名使用英文，主要目录为 `backend/`、
`frontend/`、`vision/` 和 `desktop/`。系统界面、无障碍标签、错误提示、
报告标题和模型任务指令恢复中文；文档正文支持中文。

原始转写、OCR、教师原话、词表和来源数据保持原样。已有英文报告标签作为
兼容标识保留，重新生成时替换为中文，避免同一章节重复出现。具体约定见
[语言与来源数据](../backend/tests/LANGUAGE_DATA.md)。

保留英文问题的整课采样和多来源检索支持，不改变证据配额。行为叠加只替换
派生报告章节与过期提示，不改写保存的原始课程包。

## 保留的任务恢复修复

保留 Windows 上针对 SQLite `SQLITE_IOERR_TRUNCATE` 的连接生命周期修复。
任务控制器运行期间保留一个空闲连接，停止后释放，避免工作进程退出与共享
内存清理发生冲突。对应问题见 [SQLite 上游记录](https://sqlite.org/src/info/7c103a0b7d)。
既有事务、发布恢复和数据库结构保持兼容，不屏蔽 I/O 错误。
