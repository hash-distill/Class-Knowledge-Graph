# 页面截图说明

这些图片由当前程序的生产构建实际渲染，界面语言为中文。截图尺寸为 1600 × 1160，使用独立的本地演示工作区。

| 文件 | 展示内容 |
| --- | --- |
| `overview.png` | 课堂回放、学生情况、整体积极度与同刻转写 |
| `student-review.png` | 学生行为分析与逐帧视觉复核 |
| `knowledge-graph.png` | 本课知识概念、关系与来源入口 |

课堂名称、文本、人物图形、对象框和状态分布均为合成演示数据，页面中保留“合成演示”标识。没有使用真实学生的照片、录像或个人记录，也没有运行模型生成预测。

示例评分只用于展示既有规则和软件交互，不能据此判断识别准确率、学生投入程度或教学效果。原始课堂媒体、个人工作区和推理产物继续排除在源码发布之外。
