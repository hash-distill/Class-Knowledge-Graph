# 界面语言与来源数据

应用名称为“精析智评”。界面、提示、报告标题、模型任务指令和说明文档使用中文。
仓库的文件夹与文件名使用英文，主要目录为 `backend/`、`frontend/`、`vision/` 和 `desktop/`。

原始转写、OCR、教师修订和引用保留来源语言。语言词表、否定词、数词保护规则及简繁体测试属于处理逻辑，不能为了命名规范删除或替换。

检索同时支持中文和英文问题，使用相同的整课采样与多来源证据配额。已有英文报告标题保留为兼容标识，重新生成时统一显示中文，避免重复章节。

接口字段、枚举值、桌面握手标记和现有二进制标识保持兼容。任意 Unicode 路径测试只验证文件系统能力，不是仓库的实际文件名。

README 页面截图读取既有的真实课堂处理结果，人物面部在截图显示层遮挡。检测、评分与转写保持原样；训练组片段的截图不作为独立准确率或教学效果证据。
